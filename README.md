# 🗣️ Azgardius - Smart Voice Assistant

A program that uses the **Azgardius** AI model to receive your desired sentence and read it out loud.

## Features
- Receive input as double-quoted text (`"sentence"`)
- Text-to-Speech conversion
- Automatic internet connection check
- Audio playback of AI response
